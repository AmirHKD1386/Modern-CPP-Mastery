# برنامه درسی جامع و تعاملی مدرن ++C

### از صفر مطلق تا استادی سیستم‌های بلادرنگ و برنامه‌نویسی رقابتی

یک داشبورد آموزشی تعاملی و کامل برای یادگیری **Modern C++ (C++20/23)** که سه منبع قدرتمند را با هم ترکیب کرده است:

- **C++ Primer (5th Edition)** → پایه‌های مفهومی و عمیق
- **Competitive Programmer’s Handbook (CPH)** → تفکر الگوریتمی و مسابقات
- **C++ in Embedded Systems** → اصول Zero-Overhead، ایمنی و مهندسی سیستم

---

## ویژگی‌های اصلی

- **۷ مرحله آموزشی** از صفر مطلق تا سطح حرفه‌ای (همراه با پل‌های انتقال مفهومی بین مراحل)
- بیش از ۵۰ درس با توضیحات مفهومی، کدهای تمیز، تله‌های رایج و تمرین عملی
- رابط کاربری کاملاً فارسی و راست‌چین (RTL)
- کاوشگر دروس با قابلیت فیلتر و جست‌وجو
- مقایسه‌گر کارایی (سربار زمان اجرا و حافظه)
- آزمایشگاه سنجش و چک‌پوینت‌های ترکیبی
- قالب استاندارد مسابقات (C++20) + محاسبه‌گر پیچیدگی زمانی
- **دستیار هوشمند زنده Gemini AI** (تحلیل کد، تولید مسئله و گفت‌وگوی مفهومی)

## نحوه استفاده

1. فایل `index.html` را در مرورگر باز کنید.
2. برای فعال‌سازی دستیار هوشمند Gemini، کلید API خود را در بخش مربوطه وارد کنید.
3. از تب‌های مختلف برای مطالعه دروس، تمرین و تحلیل کد استفاده کنید.

### فعال‌سازی GitHub Pages (برای مشاهده آنلاین)

1. ریپازیتوری را در GitHub بسازید.
2. فایل HTML را با نام `index.html` آپلود کنید.
3. به مسیر زیر بروید:  
   `Settings → Pages → Source → Deploy from a branch → main → / (root)`
4. چند دقیقه صبر کنید تا آدرس آنلاین فعال شود.
